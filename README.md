# EDA_SNACKS
EDA Snacks is a lightweight, interactive application designed to perform Exploratory Data Analysis (EDA) on datasets in a simple, snack‑sized format. The goal is to help data scientists, ML engineers, and learners quickly visualize, summarize, and understand their data without heavy setup.
Features:

📊 Upload CSV/Excel datasets and get instant insights

🔍 Automated summary statistics (mean, median, mode, missing values)

📈 Interactive visualizations (histograms, scatter plots, box plots)

⚡ Quick correlation heatmaps for feature relationships

🧩 Modular design for extending with ML preprocessing steps

🌐 Web interface built with Streamlit / FastAPI for easy deployment

Tech Stack:

Python (Pandas, NumPy, Matplotlib, Seaborn, Plotly)

Streamlit / FastAPI for UI and backend

Docker for containerized deployment

GitHub Actions / Jenkins for CI/CD automation

Use Cases:

Rapid EDA during ML model development

Teaching tool for students learning data analysis

Quick validation of datasets before deeper modeling

Lightweight alternative to Jupyter notebooks for sharing insights
